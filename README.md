# devops-capstone-project

This repository contains my **DevOps Capstone Project**, developed as part of the **IBM DevOps and Software Engineering Professional Certificate**.

The project focuses on building, testing, containerizing, and deploying a microservice while applying modern DevOps practices. It includes REST API development, Test-Driven Development (TDD), automated testing, CI/CD pipelines, Docker, Kubernetes, and OpenShift. The project also emphasizes maintaining high code quality and achieving at least **95% code coverage**.

## Project Overview

The goal of this capstone project is to develop and enhance a Python-based microservice by implementing RESTful APIs and applying DevOps principles throughout the software development lifecycle.

Key areas covered in this project include:

* REST API development
* Test-Driven Development (TDD)
* Automated testing and code coverage
* Docker containerization
* Kubernetes deployment
* OpenShift
* CI/CD automation
* Tekton pipelines
* DevOps best practices

This project is part of the [**IBM-CD0285EN-SkillsNetwork DevOps Capstone Project**](https://www.coursera.org/learn/devops-capstone-project?specialization=devops-and-software-engineering) course, which is included in the [**IBM DevOps and Software Engineering Professional Certificate**](https://www.coursera.org/professional-certificates/devops-and-software-engineering).

## Usage

This repository is used to complete the DevOps Capstone Project and demonstrate practical knowledge of DevOps tools, automation, testing, containerization, and cloud-native technologies.

## Development Environment

These labs are designed to be executed in the IBM Developer Skills Network Cloud IDE with OpenShift. Please use the links provided in the Coursera Capstone project to access the lab environment.

Once you are in the lab environment, you can initialize it with:

```bash
source bin/setup.sh
```
